# Preface

我在 2016 年开始接触 Go 语言。后来在工作和学习中，通过 gdb 和 delve 进行了大量调试分析，这些实践让我在理解 Go 的类型系统、标准库以及运行时相关设计实现方面，事半功倍。

由于我对底层原理充满好奇，并且喜欢追根究底。某天，我突然产生了一个疑问：**调试器究竟是如何工作的**？

- 如果只是想大致了解调试器的工作原理，阅读几篇高质量的博客或许就足够了。
- 但如果想要胜任调试器的开发工作，尤其是从零开始构建一款完整的调试器，那就完全是另一回事了。

调试器的设计、实现以及调试信息标准，构成了一个极其庞杂且深奥的工程体系。我渴望深入探索其中的奥秘；但在不断追问“为什么”的过程中，我发现市场上缺乏系统、全面且高质量的技术博客和书籍来讲解这一领域。正是这种技术空白，促使我开始编写这本书。

在编写过程中，我不仅加深了对软件开发工具链的理解，也逐渐意识到，开发一款功能完整的现代调试器，并将其中积累的宝贵设计经验整理成可以传承的书籍，具有深远意义。这不仅体现了极高的技术含量和实践价值，也有助于开发者从多维度巩固和完善自己的软件开发知识体系。因此，我决定在工作之余完成这个工程，并与大家分享这些珍贵的技术洞察。

由于作者水平有限，书中难免存在错误或疏漏，真诚地希望读者能够指出问题，让我能够继续完善相关内容。
